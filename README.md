# 即时计算器按键语义与重复等号回放后端

纯后端项目：TypeScript + Node.js + SQLite（Node 内置 `node:sqlite`，无原生依赖、无 Docker、无外部服务）。
实现一个无界面的桌面计算器**按键状态机**，通过 HTTP API 与 CLI 接收按键，输出显示值、精确分数与可追踪内部状态，并支持幂等提交与完整回放导出。

> 本项目只实现本题规定的按键语义，**不声称兼容任何品牌计算器**。

## 运行要求

- Windows 本地，Node.js >= 22.5（开发使用 Node 25）
- 仅开发依赖：`typescript`、`@types/node`

## 命令

```powershell
npm install        # 安装开发依赖
npm run build      # 编译到 dist/
npm test           # 构建并运行全部测试
npm start          # 启动 HTTP API（默认绑定 127.0.0.1 空闲端口，PORT 环境变量可指定）
npm run demo       # 运行按键演示（键 / 显示值 / 精确值 / 待操作）
npm run cli -- new                 # 新建会话
npm run cli -- key <id> 2 + 3 = =  # 逐键提交
npm run cli -- state <id>          # 查看状态
npm run cli -- export <id>         # 导出回放
```

数据保存在项目内 `data/` 目录（可用 `CALC_DATA_DIR` 覆盖），SQLite 事务原子写入按键与状态，重启后可接着输入。

## 本题规则（实现口径）

- **即时执行**：普通计算器规则，无运算优先级，无括号/函数/脚本。`2+3×4=` 得 `20`。
- **精确有理数**：十进制输入转为约分有理数，BigInt 分子分母计算，除法内部不提前舍入。`0.1+0.2=` 精确 `3/10`；`1÷3×3=` 精确回到 `1`。
- **显示**：最多 12 位小数，绝对值四舍五入（负数对称），去掉末尾无意义零；同时输出精确分数字段 `exact` 与是否发生显示舍入 `displayRounded`。输入中原样保留小数点与尾零（如 `1.00`），执行运算后才用规范显示。
- **精度预算**：输入有效数字 <= 30 位；分子/分母十进制位数 <= 60。超限进入 `PRECISION_BUDGET` 错误状态。
- **状态分离保存**：数字输入缓冲、当前操作数、累计值 `acc`、待执行运算符 `pendingOp`、最近一次等号记录 `lastEquals` 分开存储。
- **运算符**：已输入右操作数时先执行此前待运算；连续按运算符且未输入右操作数则替换（`7+×2=` 得 `14`）。
- **等号**：无新右操作数时用累计值充当（`5+=` 得 `10`）；成功后记住 `运算符+实际右操作数`，连续等号重复（`2+3==` 得 `8`）。等号后按数字开始全新计算并清除重复记录；按运算符用结果继续且不复用旧右操作数。独立输入数无待运算时等号保持值不变。
- **正负号 `±`**：切换当前输入或结果的符号；零不输出负零。重复小数点被忽略（非致命，状态不变，`ignored=true`）；前导小数点视为 `0.`。
- **百分号 `%`**：无待运算或待乘除时当前操作数 ÷100；待加减时解释为累计值的百分之几。`200+10%=` 得 `220`，`200×10%=` 得 `20`。换算值视为已输入的右操作数并被等号记忆（`200+10%==` 得 `240`）；连续百分号按同一规则继续作用于当前操作数。
- **CE / C**：CE 只清空当前输入为零，保留累计值与待运算，清除重复等号记录；C 清空全部状态为初始零。
- **错误状态**：除零（`DIV_BY_ZERO`）与精度预算失败（`PRECISION_BUDGET`）进入错误状态，之后只有 `C` 能恢复，其他按键返回 `ERROR_STATE` 且状态不变。
- **被忽略 vs 失败**：被忽略（如重复小数点、非法按键）指状态未变但可继续正常输入；失败指进入错误状态，必须 `C` 恢复。

## HTTP API

所有响应 JSON；错误码：`VALIDATION_ERROR`(400)、`KEY_INVALID`(400)、`SESSION_NOT_FOUND`(404)、`SEQ_CONFLICT`(409)、`DIV_BY_ZERO` / `PRECISION_BUDGET` / `ERROR_STATE`（体现在结果 `code` 字段）。

- `POST /sessions` → 新建会话 `{sessionId, nextSeq, state}`
- `GET /sessions/:id/state` → 当前显示、精确值、累计值、待运算、重复等号记录、错误
- `POST /sessions/:id/keys` → 单键提交 `{requestId, seq, key}`
- `POST /sessions/:id/keys/batch` → 批量提交 `{keys:[{requestId, seq, key}, ...]}`，逐键返回结果
- `GET /sessions/:id/export` → 完整回放导出（每键的序号、请求 ID、按键、逐键解释与结果）

**幂等与序号**：每个按键带严格递增的 `seq`（从 1 开始）与唯一 `requestId`。重复 `requestId` 返回首次保存的原结果（`duplicated=true`），不重复执行；`seq` 与期望不符返回 `SEQ_CONFLICT`，不偷偷重放。

合法按键：`0-9`、`.`、`+ - * /`、`=`、`±`、`%`、`CE`、`C`。

## 项目结构

- `src/rational.ts` — BigInt 有理数：约分、四则、十进制解析、12 位显示格式化
- `src/engine.ts` — 按键状态机（手写状态转换，不使用 eval 或表达式库）
- `src/store.ts` — SQLite 持久化：会话、按键记录、幂等、原子提交
- `src/server.ts` — HTTP API（`node:http`，默认空闲端口）
- `src/cli.ts` — 命令行：`new / key / state / export`
- `src/demo.ts` — 演示脚本
- `test/engine.test.ts` — 24 个测试（含持久化重启、幂等、序号冲突）

## 已验证示例

`2+3×4=20`、`2+3==8`、`5+=10`、`200+10%==240`、`200×10%=20`、`0.1+0.2=3/10`（精确）、`1÷3×3=1`（精确）、`7+×2=14`、等号后接数字开始新计算、CE 保留运算、连续正负号、除零后仅 C 恢复、中途重启续算。

## 假设与限制

- CE 后显示回退为累计值（输入缓冲已清零为 `"0"`），与部分品牌计算器显示 `0` 不同。
- 百分号换算值若超出 12 位小数，内部仍精确保存，仅显示舍入。
- 等号后直接按 `%` 时保留重复等号记录（题未明确，取一致性行为）。
- 仅本机回环地址监听；无鉴权，不适用于多用户部署。
- `node:sqlite` 在 Node 25 仍打印 ExperimentalWarning，不影响功能。
